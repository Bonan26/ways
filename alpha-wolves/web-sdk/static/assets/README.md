# Assets - Alpha Wolves

## Style Artistique: "Grungy Cartoon"
- Inspiration: Ren & Stimpy, Courage le Chien Froussard
- Trait noir organique
- Aplats de couleurs vibrantes
- Expressions grotesques

## Palette
```
Rose chair:    #E8A0B0
Fond désaturé: #2D2A3A
Noir trait:    #1A1A1A
Accent néon:   #00FF88
Rouge sang:    #CC2233
```
